# 📊 Amazon-Sales-Dashboard (Mini Project)

### 📌 **Project Overview**
- This project is a **Mini Project** where I worked with Amazon Sales Data (3,204 rows) using **Google Sheets**.
- The goal of the project was to **clean raw data** and build an **interactive sales dashboard** to visualize sales performance.
<br>

### 🛠 Tools Used
- Google Sheets
<br>

### 🔑 Key Steps
1. Cleaned and organized raw sales data (handled duplicates, blanks, and formatting issues).
2. Built pivot tables for analyzing sales performance by product and time period.
3. created interactive charts to visualize:
   - Total Sles
   - Monthly Sales Trend
   - Top-Selling Products
